# FixedRandomSpawn

Minecraft Java Edition용 Paper 26.3 플러그인입니다. Java 25가 필요하며 Paper 26.3 빌드 258의 API를 대상으로 빌드합니다.

## 설치

1. `fixed-random-spawn-2.1.0.jar`를 서버의 `plugins/` 폴더에 넣고 서버를 시작합니다.
2. `plugins/FixedRandomSpawn/config.yml`에서 `world`, `min-x`, `max-x`, `min-z`, `max-z`를 설정합니다. 기본값은 서버 기본 리스폰 월드의 X/Z 각각 -128~128입니다. 양 끝 블록을 포함하며 Y는 지형을 보고 정합니다.
3. 관리자 권한으로 `/fs reload` 후 `/fs start`를 실행합니다. 서버 콘솔에서는 앞의 슬래시를 생략합니다.

기존 RandomSpawn에서 업그레이드하는 경우 기존 JAR를 교체하고 새 설정 파일에 스폰 범위를 지정하세요. 기존 설정과 플레이어 스폰 좌표는 자동으로 이전되지 않습니다.

## 랜덤 스폰 간격

`config.yml`의 `min-distance`로 같은 월드 안의 기본 스폰 사이에 둘 최소 수평 거리를 블록 단위로 지정합니다. 기본은 32블록이며, 이전 버전의 설정에 이 항목이 없으면 32블록을 적용합니다. `0`은 간격 제한을 끕니다. 파일을 저장한 뒤 `/fs reload`를 실행하세요.

간격은 신규 배정과 `/fs reroll`에 적용됩니다. 오프라인 플레이어를 포함해 저장된 좌표를 기준으로 거리를 계산합니다. 기존 좌표는 유지되며, `/fs set`으로 관리자가 직접 입력하는 좌표는 그대로 저장합니다. 재추첨에 실패하면 기존 좌표를 유지합니다.

## 명령어

| 명령어 | 동작 |
| --- | --- |
| `/fs start` | 기능을 켜고 현재 접속 중인 미배정 플레이어에게 기본 스폰을 배정합니다. |
| `/fs stop` | 배정 좌표를 보관하면서 적용을 중지합니다. 다음 `start`에서 다시 적용합니다. |
| `/fs status [플레이어]` | 활성 상태와 배정 인원 또는 해당 플레이어의 스폰 좌표를 확인합니다. |
| `/fs reroll <플레이어>` | 현재 설정 범위에서 기존과 다른 안전한 X/Z 블록을 다시 뽑습니다. |
| `/fs set <플레이어> <x> <y> <z> [월드]` | 입력한 절대 좌표를 사용합니다. 월드를 생략하면 설정 월드를 사용합니다. |
| `/fs reload` | 설정 파일을 다시 읽습니다. 이후 랜덤 배정부터 새 범위를 사용합니다. |

`/fixedspawn`도 사용할 수 있습니다. 콘솔과 OP에 기본으로 허용되며 권한 노드는 `fixedspawn.admin`입니다. 플레이어 인수는 온라인 이름, 서버가 캐시한 기존 플레이어 이름 또는 UUID를 받습니다. 이름을 찾지 못하면 UUID를 사용하세요. 수동 좌표는 입력한 값을 그대로 사용하므로 서 있을 수 있는 위치를 지정하세요.

## 스폰 동작

- 기능이 활성화되어 있으면 첫 접속 시 배정된 위치에서 시작합니다. 재접속 시에는 마지막 위치에서 이어집니다.
- 기능을 켤 때 오프라인인 기존 플레이어는 다음 접속 시 미배정 상태라면 배정받습니다. 현재 접속 중인 사람의 배정이나 관리자의 좌표 변경은 즉시 텔레포트를 일으키지 않습니다.
- 사망 시 유효한 침대나 리스폰 정박기가 우선합니다. 침대 파괴, 위치 폐쇄, 정박기 충전 소진 등으로 개인 리스폰을 쓸 수 없으면 배정 좌표로 돌아갑니다.
- 활성 상태와 UUID별 배정 좌표는 `plugins/FixedRandomSpawn/state.yml`에 저장됩니다. 안전 조건과 최소 간격을 모두 만족하는 랜덤 좌표를 `attempts` 횟수 안에 찾지 못하면 새 좌표를 저장하지 않습니다. 아직 배정된 좌표가 없는 플레이어의 입장·리스폰에는 Paper 기본 동작을 사용합니다. 지형을 미리 생성하지 않았다면 배정 과정에서 해당 청크가 생성될 수 있습니다.

랜덤 배정은 단단한 바닥과 몸이 들어갈 두 칸을 검사하며, 바다 한가운데의 수면, 용암, 물에 잠긴 블록과 지정된 위험 블록을 건너뜁니다. 해변이나 물 위의 마른 발판은 조건을 만족하면 후보가 될 수 있습니다. 지형 검사는 배정 시점에 수행합니다.

## 빌드

Java 25와 Maven으로 `mvn package`를 실행하면 `target/fixed-random-spawn-2.1.0.jar`가 만들어집니다.
